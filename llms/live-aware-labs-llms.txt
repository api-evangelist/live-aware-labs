# Live Aware Labs (LIVE AWARE)

> Virtual playtesting and player-insights lab for game studios and researchers. LIVE AWARE
> consolidates gameplay footage, player feedback, and community discussion (Discord, Twitch,
> YouTube, internal playtests) into one dashboard and applies AI to surface trends, player
> sentiment, and critical feedback in real time. Backed by a16z.

This file is generated by the API Evangelist enrichment pipeline from the company's public web
surface. Live Aware Labs does not publish a public REST API or OpenAPI specification; its
developer surface is a PC capture SDK plus Unreal Engine and Unity plugins, distributed through
an access-gated developer portal.

## Product

- [LIVE AWARE](https://www.liveaware.io/): Virtual lab that unifies playtest video, telemetry,
  and community feedback with AI-generated insights.
- Capture SDK (PC) records video, telemetry, and in-game events.
- Engine plugins for Unreal Engine and Unity.
- No-code integrations: Slack, Jira, Monday.com, OBS, and third-party capture tools.
